開始使用

安裝

npm install %PKG_NAME%

套件內含型別宣告，TypeScript 專案不需要另外安裝 @types。沒有建置工具的頁面也可以直接從 CDN 載入，見下方的 <script> 引入。

載入方式

三種入口差在「要不要掛 window.toast」與「什麼時候注入樣式」，挑一種就好：

入口window.toast注入樣式適合
/auto會掛import 時想在任何地方直接呼叫 toast.success()
具名 import不掛第一次 show() 時模組化專案，要 tree-shake
<script>（UMD）register() 後掛register() 時沒有建置工具的頁面

side-effect 入口（最省事）

import '%PKG_NAME%/auto';

// 樣式已注入、window.toast 已掛好
toast.success('儲存成功');
toast.error('連線失敗', { position: 'bottom-center' });

具名 import（可 tree-shake、不碰 window）

import { success, show } from '%PKG_NAME%';

success('儲存成功'); // 第一次呼叫時自動注入樣式
show('自訂', { type: 'warning', duration: 8000 });

<script> 引入（UMD，全域 GlassToast）

<script src="https://unpkg.com/%PKG_NAME%"></script>
<script>
  GlassToast.register(); // 掛 window.toast + 注入樣式
  toast.info('哈囉');
</script>

API

show(message, options?)

show(message: string, options?: ToastOptions): () => void

顯示一則通知，回傳關閉這則通知的函式。message 一律以 textContent 寫入、不解析 HTML，放什麼字串都安全。

選項型別預設說明
type 'success' | 'error' | 'warning' | 'info' 'info' 變體；不認得的值退回 'info'
position 'top-right' | 'bottom-right' | 'bottom-center' 'top-right' 顯示位置；不認得的值退回 'top-right'
persistent boolean false true 時不自動消失、不顯示倒數條
duration number error 10000，其餘 5500 自動消失的毫秒數；≤ 0 視為 persistent。規則見停留時間
action { label, onClick } — 內嵌操作按鈕，見 action 按鈕 
import { show } from '%PKG_NAME%';

const dismiss = show('匯出完成', { type: 'success', position: 'bottom-right' });

// 需要提早關閉時
dismiss();
試試看

success / error / warning / info

success(message: string, options?: Omit<ToastOptions, 'type'>): () => void

等同 show(message, { ...options, type })：簽名與回傳值相同，只是省略 type。

import { success, error, warning, info } from '%PKG_NAME%';

success('儲存成功');
error('連線失敗');
warning('尚有未儲存的變更');
info('有新版本可用');
試試看

action 按鈕

傳入 action: { label, onClick } 會在訊息與關閉鈕之間放一顆按鈕；點擊後先執行 onClick，再關閉這則通知。label 同樣以 textContent 寫入。

沒有明確給 duration 時，帶 action 的通知預設不自動消失：需要使用者做決定的訊息，不該在對方讀完之前就不見。仍想自動消失，就明確指定 duration。

import { error } from '%PKG_NAME%';

error('上傳失敗，是否重試？', {
  action: { label: '重試', onClick: () => retryUpload() },
});
試試看

dismissAll(options?) / resume()

dismissAll(options?: { suppress?: boolean }): void

dismissAll() 立即清空所有位置的通知（不播退場動畫）。預設只清空，不影響之後的 show()。

選項型別預設說明
suppress boolean false true 時同時鎖住後續 show()（直接回傳空函式、不顯示），直到呼叫 resume() 或整頁重載

suppress 是給「session 過期 → 硬導航到登入頁」這類情境用的：redirect 與頁面卸載之間，還在飛的請求可能失敗並觸發新通知，先鎖住就不會閃現。SPA 不重載頁面時，記得用 resume() 解鎖。

import { dismissAll, resume } from '%PKG_NAME%';

// 只清空，之後的 show() 照常顯示
dismissAll();

// session 過期：清空並鎖住，再硬導航
dismissAll({ suppress: true });
location.assign('/login');

// SPA 不重載的情境，手動解鎖
resume();
試試看 按過 suppress 後，這頁其他按鈕都不會出現通知，直到按 resume()。

register(options?)

register(options?: { global?: boolean; injectStyles?: boolean; target?: object; closeLabel?: string }): ToastApi

把 API 掛到全域、注入樣式，並設定全域選項。/auto 入口就是不帶參數呼叫它；只用具名 import 的專案，除非要改 closeLabel 等設定，否則不需要呼叫。

選項型別預設說明
global boolean true 是否把 API 掛到 target.toast
injectStyles boolean true false 時全面停用自動注入，之後的 show() 也不會補注入；搭配自行載入 style.css，見嚴格 CSP
target object window 全域掛載的對象
closeLabel string 'Close' 關閉鈕的 aria-label，螢幕閱讀器會念出來；非英語介面請換成在地語言。套用到之後顯示的通知，空字串或非字串時退回預設

回傳值與 window.toast 是同一個物件，包含 show、success、error、warning、info、dismissAll、resume。

import { register } from '%PKG_NAME%';

// 不碰 window，直接用回傳的物件；關閉鈕改念中文
const toast = register({ global: false, closeLabel: '關閉通知' });
toast.info('哈囉');

ensureStyles()

ensureStyles(): void

把樣式以 <style data-glass-toast> 注入 <head> 最前面，重複呼叫不會重複注入。插在最前面是為了讓你的樣式表排在後面，覆蓋 --gt-* 變數時自然勝出。

  • 頁面上已有帶 data-glass-toast 屬性的 <style> 或 <link> 時直接跳過。
  • 沒有 document（SSR）時什麼都不做。
  • 通常不需要手動呼叫：自動注入開啟時，每次 show() 都會順手檢查一次。用 register({ injectStyles: false }) 關掉自動注入後，想自己決定注入時機才需要它。

行為

停留時間

error 預設停留 10 秒（錯誤訊息通常較長，也需要時間判斷怎麼處理），其他變體 5.5 秒。底部的倒數條會隨時間縮短，指示剩餘時間。

呼叫結果
info('…')5.5 秒後消失
error('…')10 秒後消失
info('…', { duration: 2000 })2 秒後消失
info('…', { persistent: true })不自動消失，沒有倒數條
info('…', { duration: 0 })同 persistent: true
error('…', { action })同 persistent: true（帶 action 且沒給 duration）
error('…', { action, duration: 8000 })8 秒後消失
試試看

位置與堆疊

  • 三個位置各有獨立的容器，第一次用到才建立，清空後自動移除。
  • 新通知排在同一位置既有通知的後面。
  • 同一位置最多同時顯示 4 則；第 5 則進來時，最舊的一則會自動關閉。
  • 關閉時高度平滑收合，其餘通知跟著補位，不會跳動。
  • 容器的 z-index 是 2147483647，不會被頁面上的 modal 或 overlay 蓋住。
試試看 「連送 6 則」會送到 bottom-right，畫面上最多只留 4 則。

無障礙

變體rolearia-live
erroralertassertive：立即打斷朗讀
success / warning / infostatuspolite：等目前朗讀結束
  • 滑鼠移上或鍵盤焦點進入時暫停倒數（倒數條同步停住），兩者都離開才恢復，符合 WCAG 2.2.1。
  • 焦點在通知內時按 Esc 關閉該則；不攔截頁面其他地方的 Esc。
  • 通知關閉時若焦點還在裡面，焦點會交還給觸發它的元素；觸發者已不在頁面上時，移到其他通知的關閉鈕，不會掉回頁首。
  • 圖示為 aria-hidden，與藥丸底的對比至少 3:1。關閉鈕的 aria-label 預設為 Close，非英語介面用 register({ closeLabel }) 換成在地語言。

降級

  • prefers-reduced-motion: reduce：改為純淡入淡出，沒有位移與 glow 脈衝；倒數條保留，因為它傳達的是剩餘時間，不是裝飾。
  • 不支援 backdrop-filter 的瀏覽器：外殼改用 --gt-bg-opaque 不透明底，維持可讀。
  • 極長的訊息最多顯示 5 行，超出以省略號截斷；不含空白的長字串會強制換行。

你的瀏覽器目前套用哪些降級，可以在 Demo 頁即時看到。

SPA 換頁

容器或注入的 <style> 被換頁流程拿掉時（例如 Astro ViewTransitions 替換整個 <body>），下一次 show() 會自動重建，不需要額外處理。樣式注入在 <head> 而非 <body>，本來就避開了 body 替換。

換頁時想順便清掉舊通知，在路由事件裡呼叫 dismissAll()：

import { dismissAll } from '%PKG_NAME%';

// Astro ViewTransitions
document.addEventListener('astro:before-swap', () => dismissAll());

樣式

CSS 變數

所有顏色與外觀都走 --gt-* 自訂屬性，範圍限定在 .glass-toast 上，不污染 :root。在你的樣式表覆蓋即可，不需要拉高權重：

.glass-toast {
  --gt-radius: 0.5rem;
  --gt-text: #333;
}

.glass-toast--success {
  --gt-icon: #0a7d4f;
  --gt-ring: 10, 125, 79;
}

表格右欄是這個頁面目前外觀下的實際值，切換頂列的「外觀」會即時更新。

深色外觀

深色是「深色毛玻璃」：低亮度半透明底配淺字，保留玻璃質感、避免夜間刺眼。只覆寫外殼、關閉鈕與 focus 外框的變數，變體色沿用淺色那組。下列任一條件成立就會套用：

  1. 系統偏好深色（prefers-color-scheme: dark）；但頁面明確標示 data-theme="light" 或 .light 時讓路
  2. <html data-theme="dark">
  3. <html class="dark">（Tailwind 慣例）

深色規則用 :where() 壓到與預設相同的權重，你的覆蓋規則照常勝出。只想改深色時的值：

[data-theme="dark"] .glass-toast {
  --gt-bg: rgba(15, 23, 42, 0.75);
}

整合

嚴格 CSP

自動注入會插入一段 inline <style>，style-src 不允許 'unsafe-inline' 時會被擋下。改成自行載入樣式檔，並關掉自動注入：

import '%PKG_NAME%/style.css';
import { register, success } from '%PKG_NAME%';

register({ global: false, injectStyles: false });
success('儲存成功');

如果樣式是用自己的 <link> 或 <style> 載入，加上 data-glass-toast 屬性，自動注入就會偵測到並跳過：

<link rel="stylesheet" href="/vendor/glass-toast.css" data-glass-toast>

SSR

所有入口在沒有 document 的環境 import 都是安全的：/auto、register()、ensureStyles() 不會做任何事。show() 需要 DOM，請只在 client 端呼叫，例如事件處理器、useEffect 或 onMounted 裡。
